WINDOWS

Setup in a few clicks

  1. Download the latest setup-win-x64.exe.
  2. Run the per-user installer.
  3. Keep optional Tesseract selected if needed.
  4. Launch from Start Menu or use intellifill in a new terminal.

Updates are available from Settings → Software Updates. Installing over an existing copy preserves settings and local database data.

Linux repositories

Install once. Update normally.

Signed APT and DNF repositories update IntelliFill OCR alongside your system. Packages include the desktop app, launcher, icon, and intellifill command.

Repository securityAPT uses a signed InRelease and dedicated keyring. DNF verifies signed repository metadata. Never add trusted=yes.
Full repository instructions →
Debian / Ubuntu amd64
sudo install -d -m 0755 /usr/share/keyrings /etc/apt/sources.list.d
sudo curl -fsSL \
  https://packages.abishekprabakaran.com/keys/intellifill-ocr-archive-keyring.gpg \
  -o /usr/share/keyrings/intellifill-ocr-archive-keyring.gpg

echo "deb [arch=amd64 signed-by=/usr/share/keyrings/intellifill-ocr-archive-keyring.gpg] https://packages.abishekprabakaran.com/apt stable main" |
  sudo tee /etc/apt/sources.list.d/intellifill-ocr.list

sudo apt update && sudo apt install intellifill-ocr
Fedora / RHEL x86_64
sudo curl -fsSL https://packages.abishekprabakaran.com/intellifill-ocr.repo \
  -o /etc/yum.repos.d/intellifill-ocr.repo
sudo dnf install intellifill-ocr
Common questions

Quick fixes, without hunting through docs.

OCR or region extraction is unavailable

Install Tesseract locally, then open Settings → Local Paths and select Auto Detect. On Windows the common executable is C:\Program Files\Tesseract-OCR\tesseract.exe. Run the System Readiness Check afterward.

APT says the repository has no Release file

Confirm the source uses HTTPS, the stable distribution, and the main component exactly as shown above. A new release reaches GitHub before repository publication finishes, so wait for the package workflow and run sudo apt update again.

APT requests an unsupported i386 index

Ensure the source contains arch=amd64. Remove older IntelliFill OCR entries that omit the architecture restriction, then refresh APT metadata.

APT or DNF does not show the newest version

Refresh package metadata after the repository workflow completes: use sudo apt update, or sudo dnf clean metadata && sudo dnf makecache.

The Linux launcher or icon is missing

Sign out and back in after installation. If needed, refresh /usr/share/applications with update-desktop-database and the hicolor cache with gtk-update-icon-cache.

In-app repository setup cannot authenticate

The setup action uses pkexec. Install your distribution's PolicyKit desktop integration or copy the manual APT/DNF commands above.
