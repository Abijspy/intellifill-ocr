Complete CLI guide

Every desktop data workflow, scriptable.

The CLI ships with every Windows, macOS, and Linux package and uses the same local document, validation, export, traceability, and SQLite services as the desktop app.

Extract and inspect

intellifill scan invoice.pdf
intellifill batch scans/*.pdf -o ./exports
intellifill inspect invoice.pdf --json
intellifill validate completed.xlsx

scan exports XLSX and PDF by default. Use --format csv,xlsx,docx,pdf, --language eng, --tesseract PATH, --no-export, or --json.

Fill a template

intellifill fill \
  --template template.xlsx \
  --source invoice.pdf \
  --source order.docx \
  --output ./exports \
  --save-db ./records/runs.db

Repeat --source up to five times. Tune matching with --threshold 0.42, override a 1-based cell with --set T,R,C=value, or select exports with --format.

Trace and audit

intellifill trace-id --mode prefix-random \
  --value ACME-
intellifill history ./records/runs.db --json
intellifill signatures contract.pdf

Trace modes are timestamp, prefix-timestamp, prefix-random, and manual. Signature candidates still require visual review; the command does not claim cryptographic verification.

Diagnose and maintain

intellifill health --json
intellifill update check
intellifill repo status
intellifill repo install

Repository commands are Linux-only. Installation uses the normal PolicyKit administrator prompt. Update checks report releases; Linux package upgrades remain managed by the system.

Exit codes0 success · 1 command/input error · 2 validation warning, missing readiness item, update, or repository action needed.
Automation scriptsUse the Bash and PowerShell batch-scan, validate-folder, and fill-and-archive examples in scripts/cli.

One script. Native updates.

For DEB, RPM, or Arch packages, the installer detects your distribution and architecture, adds the signed repository, and refreshes metadata. Flatpak users do not need this step.

Common questions

Quick fixes, without hunting through docs.

OCR or region extraction is unavailable

Install Tesseract locally, then open Settings → Local Paths and select Auto Detect. On Windows the common executable is C:\Program Files\Tesseract-OCR\tesseract.exe. Run the System Readiness Check afterward.

APT says the repository has no Release file

Confirm the source uses HTTPS, the stable distribution, and the main component exactly as shown above. A new release reaches GitHub before repository publication finishes, so wait for the package workflow and run sudo apt update again.

APT requests an unsupported i386 index

Ensure the source contains arch=amd64. Remove older IntelliFill OCR entries that omit the architecture restriction, then refresh APT metadata.

Linux does not show the newest package

Refresh package metadata after the repository workflow completes: use sudo apt update, sudo dnf clean metadata && sudo dnf makecache, or sudo pacman -Syy.

The Linux launcher or icon is missing

Sign out and back in after installation. If needed, refresh /usr/share/applications with update-desktop-database and the hicolor cache with gtk-update-icon-cache.

In-app repository setup cannot authenticate

The setup action uses pkexec. Install your distribution's PolicyKit desktop integration or run the reviewable repository installer script above.
