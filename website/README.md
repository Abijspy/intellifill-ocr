# IntelliFill OCR website

Static, dependency-free landing page for `https://abishekprabakaran.com/intellifill-ocr/`.

Deploy this directory's contents to the `intellifill-ocr` directory beneath the
Apache document root for `abishekprabakaran.com`. Relative asset paths make the
page work directly from the `/intellifill-ocr/` location.

The landing page includes the complete IntelliFill OCR CLI reference. Keep it in
sync with the canonical GitHub guide under `README.md#command-line-interface`
when commands or options change.
